# The Last Remnant 한국어 패치 (PC / Xbox 360)

**공개 버전: v0.1 · 시험 배포 / 검수 진행 중**

> [!IMPORTANT]
> **이 v0.1은 전체 검수가 완료된 정식 완성판이 아닙니다.** 번역 누락, 오탈자, UI 표시 오류, 줄바꿈 문제, 게임 진행 중 오류 등이 남아 있을 수 있습니다.
>
> **Xbox 360판은 실제 Xbox 360 본체(실기)에서의 구동 검증을 끝내지 못했습니다.** 파일 구조 검사와 패치 적용·복원 검사를 통과했더라도 실기에서 정상 작동한다고 보증할 수 없습니다. 전체 스토리, 장시간 플레이, Disc 1/2 전환도 추가 검증이 필요합니다.

《The Last Remnant》를 위한 **비공식 팬 한국어 패치**입니다. PC판과 Xbox 360 일본판(Disc 1 / Disc 2)용 패치 프로그램을 제공합니다.

## 다운로드

GitHub 저장소의 **Releases**에서 해당 플랫폼의 파일을 다운로드하세요.

| 플랫폼 | 배포 파일 | 검증 상태 |
| --- | --- | --- |
| PC (Windows) | `TheLastRemnant_KR_Patch.exe` | 파일 검사 및 패치 적용 검사 완료 / 전체 플레이 검수 미완료 |
| Xbox 360 (일본판, Disc 1·2) | `TheLastRemnant_XBOX360_KR_Patch.exe` | 패치 데이터 및 XEX/ISO 처리 검사 완료 / **Xbox 360 실기 검증 미완료** |

**버전 안내:** GitHub 공개 한국어 패치 버전은 **v0.1**입니다. 프로그램 창에 표시될 수 있는 **v1.2**는 패치툴 자체의 개발·빌드 번호입니다. 두 번호는 별개입니다. 검수용 마스터툴은 일반 사용자용 배포 대상이 아닙니다.

## 현재 한글화 범위

- **PC:** 텍스트, 한국어 글꼴, 메뉴·지역명 등 UI 이미지의 한글화 데이터를 포함합니다. 최신 수정 이미지 145장을 바탕으로 64개 이미지 패키지에 변경 내용이 반영되었습니다.
- **Xbox 360:** 일본판 Disc 1/2용 한국어 텍스트·글꼴·이미지 통합 데이터를 포함합니다. 기존 제어코드 및 메시지 구조 오류를 보정한 패치 데이터를 사용합니다.
- **두 플랫폼 모두:** 실제 게임의 모든 구간을 플레이하면서 표시·진행 여부를 끝까지 검수한 단계는 아닙니다.

## 설치 전 주의 사항

1. 플랫폼에 맞는 **게임 파일을 별도로 준비**해야 합니다. 본 패치는 게임 자체가 아닙니다.
2. 패치 전 게임 폴더와 저장 데이터를 **사용자가 별도로 백업**해 주세요. 프로그램의 자동 백업 기능과는 별개로 보관하는 편이 안전합니다.
3. 실행 중인 게임을 종료한 뒤 패치하세요.
4. 게임의 지역·버전이나 파일 상태가 지원 대상과 다를 경우 패치가 중단되거나 정상 동작하지 않을 수 있습니다. 파일 검사를 우회하지 마세요.
5. Xbox 360 ISO 방식은 새 ISO를 생성하므로 추가 저장 공간이 필요합니다.

## PC판 사용 방법

1. `TheLastRemnant_KR_Patch.exe`를 실행합니다.
2. 설치된 게임 폴더를 지정합니다. 프로그램은 게임 폴더 또는 `RushGame\CookedPC` 경로를 인식합니다.
3. 게임 파일 상태를 확인하고 한글패치를 적용합니다.
4. 완료 후 직접 게임을 실행해 텍스트와 UI 표시 상태를 확인해 주세요.
5. 문제가 있으면 패치툴의 **원본 복원** 기능을 사용하세요.

PC판은 적용할 원본 파일을 검증하고 백업합니다. 기존에 파일이 수정되어 있고 검증된 원본 백업이 없거나, 파일 해시가 지원되지 않는 상태라면 작업이 중단될 수 있습니다. 자동 생성된 원본 백업은 임의로 삭제하지 마세요.

## Xbox 360판 사용 방법

> **Xbox 360판은 반드시 일본어 정품 게임(일본판 Disc 1·Disc 2)을 사용해 주세요.** 다른 지역판이나 출처가 불분명한 게임 파일은 패치 적용 및 정상 작동을 보장하지 않습니다.

> [!WARNING]
> **Xbox 360 실기 미검증 시험판입니다.** 실제 콘솔에서의 부팅, 저장·불러오기, 전투 진행, Disc 2 전환을 보장하지 않습니다.

1. Windows에서 `TheLastRemnant_XBOX360_KR_Patch.exe`를 실행합니다.
2. **XEX / 압축해제 폴더** 또는 **ISO** 모드를 선택합니다.
3. 일본판 **Disc 1과 Disc 2**에 해당하는 폴더 또는 ISO를 각각 지정합니다. 프로그램은 디스크를 자동으로 구분합니다.
4. ISO 모드라면 새 ISO를 저장할 출력 폴더도 지정합니다.
5. 패치 적용 결과 및 오류 메시지를 확인합니다. 실제 게임 동작은 별도로 테스트해야 합니다.

- **XEX / 압축해제 폴더:** 선택한 게임 폴더의 패치 대상 파일과 `Xbox360TOC.txt`를 수정합니다. 적용 전 자료는 `TLR_KO_X360_BACKUP`에 백업하며 원본 복원 기능을 제공합니다.
- **ISO:** 입력한 ISO는 그대로 두고 파일명에 `_KR.iso`가 붙은 새 ISO를 생성합니다. 생성 파일의 구조 검증을 통과해도 실제 Xbox 360 본체에서의 구동을 의미하지 않습니다.
